FAQ

開発者向けFAQ

すべてのAPIは非SUZAKU端末で安全にno-op(何もしない)になります。1つのAPKで全Android端末に配布でき、分岐が必要な場合は isSupported をご利用ください。
GameKit SDKは無償・非独占のライセンスで提供し、商用利用も許諾されます。詳細は利用規約第7条をご覧ください。
開発者プログラム登録者には検証機の貸出を行っています。お問い合わせよりご依頼ください。
脆弱性開示ポリシーに沿ってご報告ください。誠実な報告にはセーフハーバーを適用します。
PerformanceSession.kt
// 目標165fpsの性能契約を宣言
val session = SuzakuGameKit.performance(context)
session.requestContract {
    targetFps = 165
    mode = PerfMode.SUZAKU   // 朱雀モード
    allowFan = true
}
session.onThermalHeadroom { headroom ->
    if (headroom < 0.15f) graphics.reduceParticles()
}
