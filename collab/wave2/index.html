プロキシ

ホロウ

ボンプ

02意匠 — CRAFT & COLORWAYS

色替えではなく、
街ごと写した。

配色は ライムイエロー×漆黒(公式サイトのシグナルカラーに準拠)。看板の光、路地の影、警告テープ — 街を構成する3つの明度を、そのまま筐体の3層に割り当てました。派手なのに、あの街では風景に溶ける。それがこの配色の狙いです。

新エリー・ブラックNEW ERIDU BLACK

漆黒の筐体に斜めのシグナルストライプ。標準色にして、いちばんホロウの近くにいる色。

ハザード・ライムHAZARD LIME

警告色をまとった反転仕様。ストライプは漆黒で入り、グリップのテープ質感も黒に。

プロキシ・ホワイトPROXY WHITE

静かな側の色。ビデオ屋の昼下がりみたいな白に、ライムの配線だけが走ります。

カラーはいずれも開発中の仮称・仮色です。量産版の最終色は予約開始までに確定します。

03頭脳 — DEDICATED SOC

零号 REIGO-Z1

三つの零から生まれた、都市迷宮の頭脳。

ホロウ探査のように負荷が不規則に跳ねるゲームのために、シーン検知で電力を瞬時に再配分する専用3nm SoC。街歩きは静かに、戦闘は一気に。切り替えの速さが零号の性格です。

3nm最大 3.95GHzAnTuTu 412万点

04冷却 — DEDICATED COOLING

冷巷 REIKO

裏路地の風で、冷やす。

都市の裏路地を風が抜けるように、側面デュアルダクトへ熱を逃がす専用冷却。排熱状態は背面のシグナルLEDに表示され、端末の「今」がひと目で分かります。

05ゲームの特徴 — FEATURES

FILE 01

ハザードをまとう筐体

漆黒の筐体に斜めのシグナルストライプ。グリップ側面はテープ質感の滑り止めで、長時間の探査でも手から逃げません。

FILE 02

相棒ボンプのウィジェット

通知・充電・スケジュールを、相棒「ボンプ」モチーフのウィジェットが案内。充電中は画面の中でボンプが小さく働きます(デモ表記)。

FILE 03

TVモード・テーマパック

ロック画面とホームを、あのブラウン管風UIで再構成するテーマパックを同梱。通知音はザッピング音です(デモ表記)。

TVモード・テーマパックの中身。

同梱テーマパックは「置き換え」ではなく「改装」です。OSの標準機能はそのまま、見た目と音だけがあのブラウン管に変わります(すべてデモ表記)。

正面 — TVモードのロック画面(本レンダリング)

Aロック画面「放送休止」

待受はカラーバーとノイズの狭間。持ち上げると「放送再開」のカットインで解錠画面へ。時計はテロップ風に流れます。

Bホーム「チャンネル一覧」

アプリ一覧を番組表として再構成。よく使うアプリほど太いチャンネル枠になります。フォルダは「録画一覧」。

C充電画面「働くボンプ」

充電中は画面の隅でボンプが小さく発電作業。充電速度が上がると作業も忙しくなります。満充電で、ひと休み。

▲ WARNING

ホロウ出現領域では、本端末の排熱表示が警告色に変わります — というのは作品世界の話。現実の空洞 KUDOは、負荷が跳ねた時にだけ静かに光ります。

06音と振動 — SOUND & HAPTICS

耳と手のひらにも、あの街を。

音響は作品側の監修のもと、通知・充電・警告のすべてを新エリー都の音で作り直しました。うるさくはしない — けれど、聞けば一発で分かる音に。

SOUND 01

ザッピング起動音

電源投入はブラウン管の「バチッ」から。チャンネルが合うようにロック画面へつながります。深夜モードでは無音起動に切り替わります(デモ表記)。

SOUND 02

シグナル通知音

通知は3段階の重要度で音が変わります。最重要だけが警告色のシグナル音、それ以外は路地裏の生活音みたいに控えめ。音量を絞っても背面LEDが「光で鳴らして」くれます。

HAPTICS

警報の鼓動

ゲーム中の高負荷立ち上がりを、低く短いパルスで手に伝える専用ハプティクス。画面から目を離さずに、端末の「今」が分かります。強度は5段階+オフ。
